# Robot Founder
A hands-off pixel-art "AI agent" show: an AI with a robot body autonomously founds and runs a company. You just watch.
Play: https://applesdg.github.io/robot-founder/ — spectator controls: 1x/2x/4x/8x (keys 1-4), pause (P), follow cam (F), mute (M).
Plain JS + canvas, no build step, all art procedural.
