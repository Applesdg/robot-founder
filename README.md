# Robot Founder
A hands-off pixel-art "AI agent" show: an AI with a robot body autonomously founds and runs a company — garage → loft → glass office → HQ campus → IPO (or one of six ways to fail). You just watch.

Play: https://applesdg.github.io/robot-founder/

Spectator controls: ★ highlights mode (H), 1x/2x/4x/8x (1-4), pause (P), follow cam (F), dashboard (D), mute (M). Hall of Fame stored in localStorage.

Balance check (in the browser console): `__rf.balance(200)` runs 200 headless simulations and returns the outcome distribution.

Plain JS + canvas, no build step, all art and music procedural.
